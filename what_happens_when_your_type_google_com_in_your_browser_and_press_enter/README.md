# What Happens When You Type https://www.google.com in Your Browser and Press Enter

## Project Description

This project explores the complete flow of what happens when a user types `https://www.google.com` in a browser and presses Enter. It covers the full web stack from a network and infrastructure perspective.

## Topics Covered

- DNS Request
- TCP/IP
- Firewall
- HTTPS/SSL
- Load Balancer
- Web Server
- Application Server
- Database
